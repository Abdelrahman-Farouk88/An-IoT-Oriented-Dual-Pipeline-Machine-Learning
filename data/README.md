# Backorder data

Place the two original public Kaggle CSV files here:

```text
Training_BOP.csv
Testing_BOP.csv
```

The target column is `went_on_backorder` (`Yes`/`No`). The pipeline drops rows with a missing target, maps the target to 0/1, and drops the `sku` column because it is a unique row identifier rather than a product key.

The clean training file has 1,687,860 rows and 11,293 positives (0.669%). The clean official test file has 242,075 rows and 2,688 positives (1.110%). The 300,000-row stratified modelling subset, the 240,000/60,000 internal split, and all resampling are generated by `bo_revision.py` with seed 42.

The data are not redistributed in this release. Obtain the files from the public Kaggle dataset page and follow its terms of use.
